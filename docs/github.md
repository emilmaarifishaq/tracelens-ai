# GitHub Setup

Recommended repository name:

```text
tracelens-ai
```

Recommended visibility while building the first version:

```text
private
```

Suggested description:

```text
AI-powered trace analyzer for telecom and network protocol troubleshooting.
```

After creating the GitHub repo, push with:

```bash
git remote add origin git@github.com:<owner>/tracelens-ai.git
git branch -M main
git push -u origin main
```
