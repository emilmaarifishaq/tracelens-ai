# MVP Plan

## Milestone 1: Decoder Foundation

- Upload PCAP/PCAPNG
- Run TShark JSON decode
- Store normalized trace events
- Show packet and event table

## Milestone 2: Telecom Flow Intelligence

- Extract GTPv2-C procedures
- Extract Diameter command/result information
- Correlate request/response frames
- Detect explicit error codes
- Detect missing responses and high latency

## Milestone 3: AI-Assisted Analysis

- Redact sensitive identifiers
- Build compact AI context
- Generate trace summary
- Explain selected packet/error
- Produce troubleshooting report

## Milestone 4: 5G Expansion

- PFCP
- NGAP
- NAS 5GS
- HTTP/2 SBI
- PDU session flow template
